1 Selecione o Modelo de Relatorio

Sem Projecao

Modelo completo sem projecao de indices. Inclui Conciliacao e Auditoria Documental.

Abas geradas:
Visao Geral, Estudo de Unidades, Resumo Unidades, Recebimentos, Conciliacao, Behaviour, Distratos, Recebiveis Cedente, Aging Cedente, Recebiveis Neo, Aging Neo, Inadimplencia, Base Full, Espelho de Vendas, Auditoria Documental, Cessao de Credito

Para Previa

Modelo simplificado para analise previa. Recebiveis e Aging unificados (sem separacao Cedente/Neo).

Abas geradas:
Visao Geral, Estudo de Unidades, Resumo Unidades, Relacao de Contratos, Recebimentos, Behaviour, Distratos, Recebiveis, Aging, Inadimplencia, Base Full, Espelho de Vendas

Com Projecao

Modelo completo com projecao de indices (IGP-M, INCC). Inclui Aging Projetado Cedente e Neo.

Abas geradas:
Visao Geral, Estudo de Unidades, Resumo Unidades, Conciliacao, Recebimentos, Behaviour, Distratos, Recebiveis Cedente, Aging Cedente, Aging Cedente Projetado, Recebiveis Neo, Aging Neo, Aging Neo Projetado, Inadimplencia, Base Full, Espelho de Vendas, Auditoria Documental, Cessao de Credito

3 Importar Dados (Upload de Arquivos)

Aceita arquivos .xlsx, .xls, .csv. Cada arquivo deve conter os dados conforme o modelo indicado.

Relacao de Contratos Obrigatorio
Relacao de contratos a serem auditados. Colunas esperadas: ID_Contrato, Unidade, Cliente, Empreendimento, Data da Venda, Valor de Venda, Status, Saldo Devedor.
Parcelas em Aberto Obrigatorio
Parcelas vencidas e a vencer de todos os contratos cedidos. Colunas: ID_Contrato, Unidade, Parcela, Tipo, Dt Vencimento, Valor Original, Valor Corrigido, Status.
Recebimentos Historico Obrigatorio
Recebimentos historicos incluindo quitados e detalhamento de permuta/dacao. Colunas: ID_Contrato, Parcela, Dt Venc., Data Recebimento, Valor Original, Valor Pago, Tipo.
Dados Cadastrais Obrigatorio
Dados cadastrais dos clientes. Colunas: ID_Contrato, Cliente, CPF/CNPJ, Estado Civil, Endereco, UF, Municipio, CEP.
Relacao de Unidades Obrigatorio
Relacao de unidades contendo status atual. Colunas: ID_Contrato, Unidade, Empreendimento, Area (m2), Valor de Venda, Status, Data Contrato.
Historico de Distratos Opcional
Historico de distratos do empreendimento. Colunas: ID_Contrato, Unidade, Cliente, Data da Venda, Data do Distrato, Valor de Venda, Valor Pago.
Extrato Condicional
Extrato dos ultimos 3 meses com francesinhas referentes as entradas do periodo. Colunas: Data, Descricao, Valor. Necessario para modelos com Conciliacao.
